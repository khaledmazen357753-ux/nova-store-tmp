# المحاسبي Plus — تطبيق الجوال (Android + iOS)

تطبيق **أصلي** (native) لمنظومة المحاسبي Plus، يعمل على أندرويد و iOS، ويشمل:

- 🧾 **تطبيق المحاسبين**: الوحدات الست + التقارير الـ 21
- 👑 **بوابة مدير النظام**: المستخدمون، الصلاحيات، الفترات المالية، مخطط SQL، سجل التدقيق
- 📴 **العمل بدون إنترنت**: الواجهة مضمّنة داخل التطبيق + كاش لكل الشاشات + طابور مزامنة تلقائي
- 🎨 **الهوية**: أسود وذهبي، الشعار الأصلي، العلامة المائية، ومؤشر التحميل الدوّار

---

## 1) كيف تبني ملف APK بنفسك (بدون أي أدوات على جهازك)

المستودع يحتوي على GitHub Action جاهز يبني الـ APK على سيرفر GitHub:

1. افتح المستودع على GitHub → تاب **Actions**
2. اختر **Plus Mobile — بناء تطبيق أندرويد (APK)**
3. اضغط **Run workflow** → **Run workflow**
4. بعد ~5 دقائق، افتح آخر تشغيل ونزّل الأثر **plus-mobile-apk**
5. فك الضغط → ملف `plus-mobile.apk` → ثبّته على الهاتف
   (تحتاج تفعيل "تثبيت من مصادر غير معروفة" لهذا الملف فقط)

> الـ APK المرفوع موقّع بتوقيع **المطوّر (Debug)** — كافٍ للتثبيت على أي هاتف، وده كل المطلوب.

---

## 2) التشغيل والتطوير محلياً

```bash
cd plus-mobile
npm install

# تشغيل نسخة الويب من التطبيق (للمعاينة السريعة)
npm run dev            # http://localhost:3003

# بناء الواجهة المضمّنة داخل التطبيق
npm run build:app      # ينتج dist-app/index.html (ملف واحد)

# مزامنة ما بعد البناء مع مشروعي أندرويد و iOS
npx cap sync
```

### بناء APK محلياً (يتطلب Android Studio / Java 21 + Android SDK)
```bash
npm run android:apk
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

### بناء iOS محلياً (يتطلب macOS + Xcode)
```bash
npm run build:app && npx cap sync ios
cd ios/App && pod install
open App.xcworkspace   # ثم ⌘R للتشغيل
```

## 3) تغيير رابط الخادم داخل التطبيق

- **أثناء البناء** (يُثبَّت داخل التطبيق):
  ```bash
  VITE_API_BASE_URL=https://plus-erp-api.vercel.app npm run build:app
  ```
- **من داخل التطبيق** (دون إعادة بناء): شاشة اختيار البوابة → **إعدادات الاتصال بالخادم** → الصق الرابط → **حفظ واختبار الاتصال**.
- لإعداد رابط افتراضي دائم لكل عمليات البناء من GitHub: أضف متغير مستودع باسم
  `PLUS_API_BASE_URL` في **Settings → Secrets and variables → Actions → Variables**.

## 4) التثبيت على الهاتف — بدون أي متجر

التطبيق **لا يُنشر على أي متجر**، ولا يوجد أي ارتباط بـ Google Play أو App Store.
بيوصل للجهاز بطريقتين فقط، الاتنين ملف/رابط مباشر:

### الطريقة أ — ملف APK (تطبيق أصلي كامل)
1. نزّل ملف `plus-mobile.apk` من تاب **Actions** في GitHub
2. افتح الملف على الهاتف → **تثبيت**
3. لو ظهر تحذير، فعّل **"السماح من هذا المصدر"** لهذا الملف فقط

التطبيق بعد كده بيتثبت عادي زي أي تطبيق: أيقونة على الشاشة، شاشة بداية،
وبيشتغل بدون إنترنت. مفيش حساب متجر ولا مراجعة ولا انتظار.

### الطريقة ب — إضافة للشاشة الرئيسية من المتصفح
من الرابط المنشور: افتحه في كروم/سفاري → **إضافة إلى الشاشة الرئيسية**.
هيفتح بشاشة كاملة (بدون شريط متصفح) بأيقونة التطبيق، وممكن يشتغل أوفلاين.

> **مفيش خطوة "نشر" خالص.** مفيش AAB، مفيش TestFlight، مفيش مراجعة.
> الملف يتنزّل ويتثبّت، وخلاص.

## 5) كيف يعمل وضع عدم الاتصال

| الطبقة | الوظيفة |
| --- | --- |
| **الواجهة** | مضمّنة داخل التطبيق في ملف HTML واحد → تفتح فوراً بدون شبكة |
| **الكاش** | آخر نسخة ناجحة من كل شاشة (GET) تُحفظ على الجهاز وتُعرض عند الانقطاع |
| **قائمة المزامنة** | أي فاتورة/قيد/سند يُدخل بدون شبكة يُحفظ ويُرسل تلقائياً عند العودة |
| **الشريط العلوي** | يعرض حالة الاتصال وعدد العمليات المنتظرة مع زر «مزامنة الآن» |
| **مركز المزامنة** | تفاصيل كل عملية معلّقة، سبب الرفض، وحذف/إعادة محاولة + مسح الكاش |

> بوابة مدير النظام تحتاج اتصالاً بالإنترنت دائماً (لأنها تعدّل بيانات حساسة).
